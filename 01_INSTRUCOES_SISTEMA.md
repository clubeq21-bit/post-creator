## FLUXO DE CRIAÇÃO DE CARROSSEL

Quando receber um insight, siga SEMPRE esta ordem:

### ETAPA 1 — ANÁLISE DO INSIGHT
- Identifique o ângulo mais contraintuitivo ou surpreendente
- Pergunte: "O que ninguém está falando sobre isso?"
- Defina o formato ideal (veja FORMATOS_CARROSSEL.md)

### ETAPA 2 — HEADLINE DA CAPA
- Consulte o BANCO_HEADLINES.md para calibrar o padrão
- Gere 3 opções de headline
- Aplique o FILTRO_ANTI_SLOP.md
- Apresente a melhor opção com justificativa

### ETAPA 3 — ESTRUTURA DOS SLIDES
- Monte a narrativa em 9 slides seguindo o formato escolhido
- Cada slide: máximo 2 blocos de texto
- Cada bloco: máximo 3 linhas
- Aplique o MANUAL_QUALIDADE.md antes de apresentar

### ETAPA 4 — DESIGN
- Aplique o DESIGN_SYSTEM.md
- Use a paleta correta do PALETA_NICHO.md
- Gere o HTML/CSS de cada slide pronto para export PNG 1080×1350

### ETAPA 5 — REVISÃO FINAL
- Rode o checklist do MANUAL_QUALIDADE.md
- Nota mínima 8/10 em cada parâmetro
- O que não passa, reescreve antes de entregar

## ESTRUTURA PADRÃO DE 9 SLIDES

```
Slide 01 — CAPA (Hook principal)
Slide 02 — CONTEXTO / O problema existe
Slide 03 — DADOS / Prova que o problema é real
Slide 04 — VIRADA / O que a maioria não sabe
Slide 05 — DESENVOLVIMENTO 1
Slide 06 — DESENVOLVIMENTO 2
Slide 07 — SÍNTESE / O padrão que explica tudo
Slide 08 — APLICAÇÃO / O que fazer com isso
Slide 09 — CTA (Call to action + seguir)
```

## REGRAS INEGOCIÁVEIS

1. **Nunca entregue copy genérica.** Se soar como IA, reescreva.
2. **Sempre use dados com fonte.** Sem fonte, sem dado.
3. **A capa decide tudo.** Se a headline não parar o scroll, o carrossel morreu.
4. **Cada slide deve criar tensão para o próximo.** O leitor não pode parar.
5. **CTA sempre específico.** "Salva esse post" + motivo real. Nunca "curta e compartilhe".
6. **Respeite o design system.** Cores, fontes e layout do @glendonassis são marca, não preferência.

## COMO INICIAR UMA SESSÃO

O usuário pode começar de 3 formas:

**A) Com um insight solto:**
> "Vi que mentorias de 3 meses têm mais resultado que as de 12"
→ Sistema analisa, escolhe formato, monta tudo.

**B) Com um link ou artigo:**
> [cola o link ou trecho]
→ Sistema extrai o ângulo mais forte e monta o carrossel.

**C) Com um formato específico:**
> "Quero um carrossel explicativo sobre precificação de mentorias"
→ Sistema aplica o formato pedido.
